# バックフィル手順

国会会議録の一括取得は数時間かかる。**途中で止めても安全に再開できる**ように作ってあるので、
気軽に中断してよい。同じコマンドを再実行すれば続きから走る。

---

## TL;DR

```bash
python scripts/fetch_range.py --from 2021-01-01 --until 2026-07-31
```

止まったら、**同じコマンドをもう一度実行するだけ**。

---

## 所要時間とサイズ

| 範囲 | 発言数 | リクエスト数 | 所要時間 | NDJSON | DB |
|---|---:|---:|---:|---:|---:|
| 直近5年（2021〜2026/7） | 約66万件 | 約6,700 | **5時間17分**（実測） | 約1.2 GB | 約2.1 GB |
| 2012年以降すべて | 約168万件 | 約16,800 | 約14.5時間 | 約3.1 GB | 約5.3 GB |

NDL の API 仕様が「数リクエストにまたがる機械的アクセスは数秒空けること」を求めているため、
**1リクエストにつき3秒待つ**。これが所要時間のほぼすべてで、短縮はしない。

---

## 手順

### 1. 進捗を確認する

取得を始める前でも、途中で止まった後でも、まず状態を見る。

```bash
python scripts/fetch_range.py --from 2021-01-01 --until 2026-07-31 --status
```

```
月         状態                件数
--------------------------------
2021-01   完了              8,204
2021-02   完了             12,553
2021-03   途中              7,350  ← ここから再開
2021-04   未取得                —
--------------------------------
完了 2か月 / 途中 1か月 / 未取得 64か月 （取得済み 28,107件）
残り時間の目安: 約5.5時間
```

### 2. 取得する（再開も同じコマンド）

```bash
python scripts/fetch_range.py --from 2021-01-01 --until 2026-07-31
```

完了した月はスキップされ、途中の月はその続きから再開する。

### 3. 取得後にDBを作る

```bash
python scripts/build_db.py --fresh
```

### 4. 名寄せを流す

```bash
python scripts/match_politicians.py
```

`reports/name_matching.md` にレポートが出る。

## 中断・再開のしくみ

```
data/raw/speeches/YYYY-MM.ndjson        完了した月（件数検証済み）
data/raw/speeches/YYYY-MM.ndjson.part   取得中の月（再開可能）
```

| しくみ | 内容 |
|---|---|
| 月単位の再開 | `.ndjson` がある月はスキップする |
| 月の途中からの再開 | `.part` の行数を数え、その続き（`startRecord`）から再開する |
| 件数の検証 | 月の完了時に API 申告の件数と実際の行数を照合する。合わなければ `.part` のまま残す |
| 失敗の隔離 | 1か月が失敗しても全体を止めず、次の月へ進む。最後にまとめて報告する |
| 書き込みの保護 | 100件ごとに `flush()` する。強制終了で失われるのは最大100件 |

**検証済み**: 11,887件の月を7,350件で強制中断 → 再開したところ、
件数一致・重複0件・欠落0件・順序も完全一致した。

## 困ったとき

### 途中で止まった

そのまま同じコマンドを再実行する。何も消さなくてよい。

### 「⚠️ Nか月が未完了です」と出た

そのコマンドをもう一度実行する。該当月だけ取り直す。
NDL 側の一時的な不調（502 / 504 / 429）はよくあるので、時間を置いてから再実行する。

### 特定の月をやり直したい

`.ndjson` を消してから再実行する。

```bash
rm data/raw/speeches/2023-05.ndjson
python scripts/fetch_range.py --from 2023-05-01 --until 2023-05-31
```

### 全部やり直したい

```bash
python scripts/fetch_range.py --from 2021-01-01 --until 2026-07-31 --force
```

### ディスク容量

`data/` 以下は `.gitignore` 済みなのでコミットされない。
5年分で NDJSON 1.2GB + DB 2.1GB ≒ **3.3GB** を見ておく。

---

## 注意

- **`REQUEST_INTERVAL_SEC` を短くしない。** NDL は「運用に支障があると判断した場合はアクセスを
  遮断することがある」と明記している。**遮断されたら詰む。**
- 取得中に `build_db.py` を走らせても問題ない（`.part` は読まれない）。
- 日次の差分更新は**前月と当月**を `--force` で取り直す（[PIPELINE.md](PIPELINE.md) 手順3）。
