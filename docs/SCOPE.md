# やらないことと、その理由

**判断に迷ったらここに戻る。**
このリストは慎重を期しているだけでなく、**個人が持続的に運営できる範囲を決めている。**

---

## やらないこと

| | 理由 |
|---|---|
| ❌ **独自の点数付け・ランキング・議員の評価** | 公職選挙法（落選運動該当の回避）・名誉毀損 |
| ❌ **議員ごとの発言数の分布・多い順の一覧** | 発言数は委員会の所属と役職で決まる（大臣は答弁で跳ねる）ので、並べると事実上の議員評価になる。**会派ごとの分布は出す**（分母で割った率・降順のみ）。**`/politicians` の既定は氏名のよみ順**——表の見出しで利用者が並べ替えることはできるが、運営が多い順で出すことはしない（2026-08-17 に既定を発言数順から変えた） |
| ❌ **LLM に「立場が変わった」を判定させ、事実として出す** | 誤判定が必ず出て、それがそのまま名誉毀損リスクの本体になる |
| ❌ **報道記事の収集・転載・スクレイピング** | 著作権。かつ**必要なかった**（争点語は国会会議録だけで抽出できると実証済み） |
| ❌ 公的活動以外の個人情報（家族・住所・病歴等） | 個人情報保護法。扱う情報を公的活動に限定する |
| ❌ 選挙期間中の有料ネット広告 | 公職選挙法 |
| ❌ 常時稼働のサーバー / DBサーバー / APIサーバー | 運用コストと工数。壊れて困るものを作らない |
| ❌ Vercel でのホスティング | 帯域課金。バズると個人の財布が痛む |
| ❌ X (Twitter) API への課金 | 最安でも月$100超で、予算 月1,000円 の15倍以上 |
| ❌ 全期間（1947年〜）の一括取り込み | R2 が 3.3GB → 約8.1GB になり無料枠の余裕が消える |
| ❌ 全発言への AI 処理 | 初回55,000円・年11,000円。予算に収まらない |

**「評価をしない・原典に必ず飛ばす・生成AIの出力を事実として出さない」**
——この3つを守る限り、個人運営で背負うリスクは十分小さいと判断している。

## 原則: 変遷を「判定」せず「並べる」

LLM に「この議員の立場が変わったか」を判定させ、その結果を事実として表示することはしない。
誤判定が必ず出る。

**発見するのは読者。** 運営者は「国会会議録がそう記録している」と言うだけの立場でいる。
法務的にも工数的にも圧倒的に軽い。

「争点別のスタンス比較」も同様に、自動分類ではなく**争点キーワードでの絞り込み**で
構成し、主観判定を挟まない。

## 法的な整理

> 以下は専門家のレビューを経ていない。収益化・評価機能の追加など、
> リスクプロファイルが変わる変更を加えるときは弁護士に確認すること。

### 追い風

**著作権法40条1項** — 公開の場での政治上の演説・陳述は、方法を問わず自由に利用できる。
国会答弁がこれに当たる。

**国会会議録** — 国立国会図書館が公式APIを提供していて、個々の発言は自由に利用できる。
ただし**データベース自体の著作権はNDLに帰属する**ため、丸ごとミラーして
「NDLのDBの代替」を作る形は避け、独自の構造化・分析を加えた別物にする。

### 40条1項但し書きへの対応

但し書きに「**同一の著作者のものを編集して利用する場合を除き**」とあるため、
**「特定議員の発言だけを集めた編集物」に見えない設計**にする。

- 議員ページの発言一覧は **抜粋（160字前後）＋原典リンク** に留める
- 全文は個別発言ページで、**会議という文脈の中で**表示する
- 全レコードに会議名・日付・原典URLを機械的に付与する（著作権法48条の出所明示義務）

> 国会会議録は公的記録であり著作物性の争点自体が薄い領域。過度に恐れる必要はないが、
> 「全文ダンプの編集物にはしない」という設計指針は守る。

### 法務の最小セット

**これが揃うまで公開しない**、としていた条件。**すべて満たしている。**

| | 状態 |
|---|---|
| 全レコードに原典リンク | ✅ `speech_url`。**これ自体が最強の防御になる** |
| 免責事項・訂正依頼窓口 | ✅ `/disclaimer`。受けた後の直し方は [CORRECTIONS.md](CORRECTIONS.md) |
| プライバシーポリシー | ✅ `/privacy`。検索語は送信していない・Cookie もローカルストレージも使っていない |
| 運営者表示 | ✅ ハンドルネーム＋連絡先メール（`site/src/lib/operator.ts`） |
| 特定商取引法表記 | 不要（非商用のため） |
| 弁護士レビュー | 省略中。**評価機能を足す / 広告を入れる時点で必須**に切り替える |

**アクセス解析を入れたら `operator.ts` の `analytics` を必ず埋めること**（`/privacy` の記述が変わる）。

### 正確性の限界（`/disclaimer` に書いてあること）

- **名寄せ** — 発言数ベースで99.6%が一意に確定しているが、100%ではない
- **会派から政党への対応づけ** — 統一会派があるので機械的には決まらない。
  特定できないものは空欄にしてある
- **抜粋の位置** — 機械的に切り出しているので、文意を代表しないことがある
- **直せないもの** — 会議録そのものの内容と、発言の削除には応じられない

## 期待値の調整が必要な事実

**投票行動は全議案分を取得できない**（将来の Phase 2）。

| 院 | 状況 |
|---|---|
| 参議院 | 押しボタン式投票の**個人別結果が公開**されている → 取得可能 |
| 衆議院 | **起立採決には個人別の記録が残らない**。記名投票の分のみ → 部分的 |

「衆院議員の全議案賛否一覧」は**原理的に作れない**。コア価値は発言側に置く。
